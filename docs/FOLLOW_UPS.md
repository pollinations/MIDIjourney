# MIDI Journey 2 roadmap

- **Multi-clip MIDI input:** use several Live MIDI clips together in one prompt. Define selection and how each clip appears in the prompt before implementing.
- **Native distribution:** Developer ID signing and notarization for the macOS component; verify installation on another machine.
- **MCP control:** explore explicit tools for reading state, setting prompts, generating MIDI and writing to a specified empty slot. Preserve existing clips and report completion or errors.
- **Performance demo:** create and record a roughly 30-minute MIDI set with melodic, bass and drum clips, instruments and effects. Verify reliable clip transitions and synchronized screen/Ableton audio capture first.
